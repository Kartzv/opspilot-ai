# API

A API sera criada apenas na Fase 7, usando FastAPI.

Nesta fase inicial, o projeto roda somente pelo terminal.

## Objetivo Futuro

Transformar o OpsPilot AI em uma API REST para que outros sistemas possam criar, consultar e atualizar dados operacionais.

## Rotas Futuras

```txt
GET /contacts
POST /contacts
GET /contacts/{id}
GET /contacts/search?phone=
POST /requests
GET /requests
PATCH /requests/{id}/status
POST /tasks
GET /tasks
PATCH /tasks/{id}/status
GET /reports/summary
```

## Conceitos que serao praticados

- HTTP;
- rotas;
- parametros de rota;
- query parameters;
- body JSON;
- schemas;
- validacao;
- status codes;
- organizacao de endpoints.
