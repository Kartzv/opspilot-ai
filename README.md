# OpsPilot AI

OpsPilot AI sera uma plataforma backend de operacoes com IA para pequenas empresas.

O projeto comeca de forma simples, rodando no terminal com Python puro, e evolui aos poucos para uma aplicacao backend completa com PostgreSQL, FastAPI e IA generativa.

## Objetivo

Construir uma plataforma backend em Python para centralizar contatos, conversas, tarefas e solicitacoes operacionais.

No futuro, o sistema devera ser capaz de:

- cadastrar contatos;
- registrar solicitacoes;
- organizar tarefas;
- classificar demandas;
- detectar duplicidades;
- gerar relatorios;
- sugerir proximas acoes;
- usar IA para interpretar mensagens operacionais.

## Problema Resolvido

Pequenas empresas recebem mensagens por WhatsApp, e-mail, formularios, Instagram, site, CRM, planilhas e automacoes. Muitas vezes essas informacoes ficam espalhadas, duplicadas ou sem acompanhamento claro.

O OpsPilot AI nasce para centralizar essas informacoes e ajudar a transformar mensagens soltas em operacao organizada.
